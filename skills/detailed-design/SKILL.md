# 详细设计文档

## 选择输出

文档输出读取内置 `assets/template.xml`，不依赖原飞书模板。用户给飞书链接时选择飞书，指定 Word／docx 时选择 Word，同时指定则两种都交付。未指定时简短询问输出形式，并继续不依赖答案的代码调研。Word 用户无需连接飞书。仅整理或提交 FR 时按下节执行，无需先创建飞书或 Word。

## GitHub Feature Request

用户要求提FR、更新已有Issue、按详设同步FR或处理FR审核时，先读 [GitHub FR 工作流](references/github-fr.md)。以目标仓库当前模板和检查规则为准，不把本技能的详设模板直接当作Issue格式。给出Issue URL时优先原地更新；仅准备草稿不等于获准提交。写入授权已明确时完成提交及回读，不重复询问。

## 调研与写作

**详设必须与关联 FR 对齐。** 已有 FR 时，在编写或迭代详设前读取最新正文和已确认的评审结论，将 FR 的需求逐项映射到设计与验收用例。两端的目标、首期范围、非目标、职责边界、关键选型、版本约束及验收口径必须一致；详设可以展开实现细节，但不得静默扩大、缩小或改变 FR 的需求。发现冲突时，以用户明确确认的最新需求和评审决定为依据处理，不因某端更新时间更晚就自动认定其正确；依据不足时标明冲突并询问关键决策。

1. 读取适用 AGENTS.md，检查实际入口、配置、加载、调度、状态、验证和汇总。先发现事实再询问，只有文档可访问时声明未做代码核对。
2. 背景先明确上层产品、入口、执行引擎、适配落点与仓库职责；核对 Python API、HTTP、CLI、子进程等实际调用方式。
3. 外部协议、模型和基准查官方一手资料，记录版本和日期。区分官方支持、本地可配置、运行验证通过、指定版本可复现。未执行不写通过，不为调研自动发起付费测试。
4. 按模板填写代码树、模块、接口、状态与异常、使用、测试及发布。代码树标记新增／修改／复用，说明不改动范围；拟新增文件和接口不得描述为已存在。多仓库分别列明安装环境和交付职责。
5. 数据相关项目写来源、国内获取（优先核验 ModelScope 等可用渠道）、离线方式、版本哈希、字段映射、目录发现、确定性筛选及完整性。不虚构镜像地址。
6. 验收明确指标分子分母、单位、绝对／相对误差、阈值边界、运行次数、聚合方式及错误缺失处理。区分客户端与实际推理硬件。含糊条件保留原文并列待确认，不擅自选口径；不取最佳运行冒充均值。
7. REQ 与 TC 关联；不伪造负责人、日期、版本或测试结果。专项按实际需要裁剪。关键字段与结论适度加粗，说明与限制用斜体，标题不带模板标记。必要的架构、执行和验收分支配图，图文保持一致，不放空白图占位。
8. 以官方测评精度对齐为目标时，区分官方公布成绩、官方实现直接实测和适配路径实测。先核实版本、模型快照和配置，设计官方路径冒烟、确定性工具/模型响应/评分差分、官方全量基线复现及适配精度验收。每条用例写前置输入、步骤、预期及证据；冒烟通过或总分接近不能替代语义一致性。参考条件不足时保留实测并标记复现未验证，不静默换基线、放宽阈值或自动调用付费API。
9. Agent或运行时选型给明确决策与依据：判断提示、工具、历史、预算、重试、停止、超时取消及状态交接是否改变评测语义。区分复用公共能力与替换执行循环；非等价路径分别报告，不冒充官方同条件复现。相关指标和流程按项目需求裁剪，不预设固定模型、题数、次数或阈值。

## 内容源与交付

以 UTF-8 DocxXML 作为共同源。模板资产中的维护说明和作者不是新项目事实，输出时删模板说明，替换标题及修订记录。

- 飞书：读取 `references/feishu.md`，先读最新目标，局部写入后回读。保留用户修改和资源；不擅自恢复已删除章节，不重复询问已有的写入授权。
- Word：读取 `references/word.md`，使用 `scripts/export_docx.py` 生成真实 docx；不以重命名 Markdown 代替 Word。

迭代修改时同步核对代码树、配置、图示、接口和测试，避免通过追加段落累积矛盾。明确要求写入才修改外部文档。遇到实际权限阻塞说明原因并保留本地稿，不宣称写入成功。

用户要求同时改详设与FR时，先读取两端最新状态，建立本轮变更清单，分别局部更新并回读；核对职责、选型、测试编号、顺序、公式、异常状态和待验证项一致。只获准修改一端时，在该端落实已确认需求并列出另一端所需同步修改，不擅自写入未授权目标。交付前逐项检查FR需求是否有对应设计和测试、详设是否存在FR未涵盖的范围变化；未解决的差异必须明确列出，不能宣称已对齐。任一端失败应报告实际完成范围，不把另一端成功当作整体完成。

交付前检查完整性、版本证据、字段传递、状态隔离、失败恢复及结果口径；重新打开文件或回读飞书。Word 无渲染器时如实说明只做结构校验。最终提供可点击的飞书或绝对路径 docx 链接，简述关键未确认项；两种输出核对同一内容版本，任何产物不含真实密钥。
