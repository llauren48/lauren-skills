# 飞书输出

模板已固化，无需访问原模板。目标来自用户，只有明确要求新建时才创建新文档。

优先使用现有飞书工具；可用 lark-cli 时使用 docs +fetch／+update。环境提供 lark-doc 技能时读取对应读取、更新与 XML 参考；wiki 按资源路径解析。

1. 读最新正文、block ID、资源和版本；修改章节先定位再获取上下文。用户可能已删改内容，不能用旧快照覆盖。
2. 对已有文档使用局部 block_replace／block_insert_after；保留标题、图片、表格、评论和画板，非明确整篇重建不 overwrite。
3. 富文本使用 b、em、table 等真实标签。多行 XML 通过 UTF-8 文件或 stdin 传递，避免 shell 插值风险。
4. 图示按可用画板技能生成，或插入已检查的本地图片；更新已有画板复用 token，检查渲染与正文一致，不用空图替代完成。
5. 每轮检查 success、warnings 并回读影响范围；结构变化后按最新 ID 编辑，失败不盲目重试造成重复章节。

权限或自动审批阻止时解释实际阻塞，保留本地完成稿；未经用户选择不新建另一个在线目标。双格式输出时导出画板为图片，Word 源中的 img 使用本地 path，而非飞书 token。
